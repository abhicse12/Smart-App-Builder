# React Vite Applications

Use React when React is selected by the user or explicitly requested.

React applications can use Vite as the frontend build tool.

A typical React Vite application contains:

- frontend/package.json
- frontend/index.html
- frontend/vite.config.js
- frontend/src/main.jsx
- frontend/src/App.jsx
- frontend/src/index.css

Use React components to divide the UI into reusable parts.

Use React Router when the application requires multiple pages.

Do not introduce a backend unless the application requirements require server-side APIs, authentication, database operations, or other backend functionality.
